# Stock-Price-Prediction-Forecasting-System

An end-to-end Machine Learning and Deep Learning based stock market forecasting system that predicts next-day stock prices using historical financial data, technical indicators, and time-series analysis. The project supports dynamic ticker-based prediction for multiple companies and provides real-time forecasting through an interactive Flask web application.

---

# 🚀 Features

- 📊 Real-time stock data collection using Yahoo Finance API
- 🤖 Deep Learning based stock prediction using TensorFlow/Keras
- 📈 OHLC (Open, High, Low, Close) data analysis
- 🧠 Time-Series Forecasting with dynamic sequence generation
- 🔄 Multi-company ticker support
- 📉 Actual vs Predicted stock visualization
- 📌 Model evaluation using R² Score, RMSE, and MAE
- 🌐 Flask-based interactive web application
- ⚡ Automated preprocessing and prediction pipeline

# 📂 Project Workflow

1. Fetch historical stock market data using Yahoo Finance API  
2. Perform data preprocessing and normalization  
3. Generate time-series sequences for model training  
4. Train Deep Learning models on OHLC financial data  
5. Evaluate model performance using ML metrics  
6. Predict next-day stock prices dynamically  
7. Visualize actual vs predicted trends  
8. Display predictions through Flask web interface
